# Student Record Management System in C

## 📌 Project Overview

The **Student Record Management System** is a menu-driven application developed using C programming and Singly Linked Lists.

This project allows users to manage student records efficiently through various operations such as adding, deleting, modifying, displaying, sorting, reversing, and saving student information.

The project uses dynamic memory allocation to create linked-list nodes at runtime and file handling to store student records.

- Understand dynamic memory allocation using `malloc()` and `free()`.
- Perform insertion, deletion, and modification operations.
- Implement searching and sorting techniques.
- Reverse a linked list using pointers.
- Store student records using file handling.
- Develop a modular application using multiple C source files.
- Understand compilation using Makefile.

## ✨ Features

### 1. Add Student Record
- Creates a new student node dynamically.
- Accepts student name and percentage.
- Automatically assigns a roll number.
- Inserts the new node into the linked list.

### 2. Display Student Records
- Displays all student records.
- Shows roll number, student name, and percentage.

### 3. Delete Student Record
Supports two deletion methods:
- Delete by roll number.
- Delete by student name.

Uses pointer manipulation to unlink nodes and `free()` to release allocated memory.

### 4. Modify Student Record
Supports searching records using:
- Roll number
- Student name
- Percentage

Allows modification of student name and percentage.

### 5. Sort Student Records
Supports two sorting operations:
- Alphabetical sorting by student name.
- Sorting by percentage in ascending order.

### 6. Reverse Linked List
- Reverses the singly linked list.
- Changes node links using pointers.
- Updates the head pointer to the new first node.

### 7. Save Student Records
- Saves student details into a file named `studen.dat`.
- Stores roll number, name, and percentage.

### 8. Delete All Records
- Deletes all nodes from the linked list.
- Releases dynamically allocated memory.
- Updates the head pointer to `NULL`.

### 9. Exit Options
- Save and Exit.
- Exit Without Saving.
